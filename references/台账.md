## 三、本机已知陷阱（踩过，别再踩）

1. **`MAVEN_HOME` 老进程看不到**：进程环境是启动时快照。脚本必须注册表兜底读 `HKLM:\SYSTEM\CurrentControlSet\Control\Session Manager\Environment`。
2. **`mvn` 在当次会话常解析不到**（进程 PATH 是环境变量生效前继承的旧值）；**新开终端可直敲 `mvn`**——注册表 Machine PATH 含 `%MAVEN_HOME%\bin`，Path 值类型 `ExpandString`（2026-10-15 核实：把注册表 Path 按 OS 规则展开后 `mvn -version` 正常输出 3.10.0）。拿不准就显式调 `$MAVEN_HOME\bin\mvn.cmd`。
3. **`where node` 第一条是 DSH 自带运行时** `%APPDATA%\dsh-tauri\runtime\node.exe`（v22.22.0），不是 nvm 的。查 Node 版本必须走 nvm symlink。
4. **`nvm list` 非交互无输出**：读 `F:\nvm` 目录 + `F:\nodejs` 链接目标即可。
5. **IDEA 版本只认 `build.txt` / `product-info.json`**，目录名与注册表 `DisplayVersion` 都是安装时的旧值（自动补丁升级不改名）。
6. **`-File` 传参不按逗号拆数组**：PS 5.1 里 `powershell -File x.ps1 -Only A,B` 会把 `A,B` 当**一个** token（外层 pwsh 甚至会把逗号变空格）。脚本内必须自己 `-split '[,;\s]+'`；且拆分结果**不能赋回 `[string]` 类型的 param**（会被空格拼回一根字符串），要用独立 `[string[]]` 变量。
7. **PS 5.1 无 BOM 的 .ps1 按 ANSI 解析**，中文必炸 → 脚本源码纯 ASCII，中文文案放 JSON 配置运行时读。
8. **Inno Setup 静默安装：`/DIR=` 的值必须整体带引号**。用 `Start-Process -ArgumentList @('/DIR=F:\Program Files (x86)\Git', ...)` 时参数仍按空格拆开，实际装到 `F:\Program`，且升级场景下旧目录已被卸载 → `git` 命令突然消失。正确写法：把所有参数拼成**一条字符串**，含空格的值加引号 `'/DIR="F:\Program Files (x86)\Git"'`。装完立刻 `Test-Path <预期目录>` + `Get-Command git` + 查注册表 `InstallLocation` 三重核对。
9. **PS 5.1 双引号字符串里 `"[$([...])] ..."` 会解析失败**（`Missing ] at end of attribute or type literal`）：`$()` 子表达式内再出现 `[...]` 被误判。改为先赋值给变量再插值。
10. **.NET 文件 API 不认 PowerShell 的 `cd`**：`[IO.File]::ReadAllBytes('rel.txt')` 仍按进程工作目录解析 → 一律用绝对路径或 `$root + $f` 拼接。

**本批踩的坑（已固化为 SKILL.md 铁律）**：

1. **workspace.xml 二次编码事故**：第一轮替换脚本用 `Get-Content -Raw` 读 + `Set-Content` 写，PS 5.1 按 GBK 解码 UTF-8 → 中文乱码且个别字吃掉 XML 引号，17 个文件中招。**修法：字节级读写**（`ReadAllBytes` → `GetEncoding(28591)` → 替换 → `GetBytes` → `WriteAllBytes`）。
2. **替换脚本路径拼错**：46 个替换结果被误写到 `F:\` 根目录（文件名形如 `_idea-workspase-xxx_.idea_workspace.xml`），原文件未动。**修法：dry-run 先打清单、双指标校验、写前备份**。
3. **路径形态不止一种**：绝对路径、`$PROJECT_DIR$/../../maven/...`、可变层级 `$PROJECT_DIR$/(../)+maven/...` 三种并存，三轮才收敛；负向断言 `(?! -)` 保护公司定制副本。
4. **沙箱限制**：`Remove-Item -Recurse/-Force` 一律被禁；替代 `cmd /c rd /s /q`、`Clear-Content` + `$file.Delete()`、`[IO.File]::WriteAllText`。
